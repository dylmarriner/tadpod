# Tadpod design system

This folder contains the self-contained Tadpod brand system bundle used to
review the visual language and component kit.

## Preview

Open `brand.html` for the brand system overview. It includes the supplied
product identity asset, the refreshed midnight telemetry presentation, role
tokens, typography, voice, imagery guidance, and embedded component-kit
previews.

The generated files under `system/` are kept beside the overview so its local
previews and artifact links resolve without a build step.
