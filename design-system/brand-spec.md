# Tadpod futuristic brand specification

## Summary

Tadpod is a high-contrast operating surface: monochrome product identity, near-black instrument panels, white work areas, and a single blue signal that marks the next action.

## Tokens

```css
--bg: #ffffff;
--surface: #f7f8fa;
--fg: #111111;
--muted: #6b7280;
--border: #d9dee7;
--accent: #1677ff;
```

Display and body use `Inter, system-ui, -apple-system, Segoe UI, Helvetica Neue, Arial, sans-serif`.

## Observed rules

1. The supplied mark is a monochrome RELX product photograph with smoke on a white field.
2. Futuristic character is expressed through dark control surfaces, scan rails, compact labels, and deliberate data hierarchy.
3. Blue is a signal color for primary action, selected state, and active system telemetry.
4. Structural geometry remains Tadpod: 8px corners, 1px borders, 8px rhythm, and 44px controls.
5. Motion is short and operational; no decorative animation competes with staff workflows.
